## ✨ Tính năng nổi bật

- 🐉 **Hero Tương Tác "Bé Rồng Cầu Rồng":** Bấm nút để xem Bé Rồng phun lửa trái tim 🔥, phun bong bóng nước mát lạnh 💧 và chuyển đổi bầu trời **Ngày Nắng Mỹ Khê ☀️ ↔ Đêm Sông Hàn Lung Linh 🌙**.
- 🗺️ **6 Điểm Đến Biểu Tượng (Animated SVG):** Cầu Rồng, Cầu Vàng Bà Nà Hills, Bãi Biển Mỹ Khê, Bán Đảo Sơn Trà (Voọc Chà Vá), Ngũ Hành Sơn và Cầu Tình Yêu.
- 🍜 **Hộ Chiếu Ẩm Thực Đà Nẵng (Foodie Stamp Collector):** Tương tác đóng dấu mộc `ĐÃ MĂM MĂM ♥` cho 5 đặc sản trứ danh xứ Quảng.
- ⏰ **Lịch Trình 24 Giờ Yêu Đà Nẵng:** Gợi ý hành trình từ bình minh 05:30 đến đêm sông Hàn 21:00.
- 🌐 **Đa Ngôn Ngữ (`VI` / `EN` / `JA`):** Chuyển đổi tức thì không nhấp nháy trang.

## 🚀 Chạy dự án Local & Deploy lên Vercel

```bash
# Cài đặt dependencies
npm install

# Chạy môi trường phát triển (http://localhost:4321)
npm run dev

# Build bản production tĩnh (dist/)
npm run build
```
